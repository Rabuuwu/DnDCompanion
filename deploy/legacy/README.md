# Starsze jednostki systemd

Te jednostki pozostają wyłącznie jako dokumentacja wcześniejszego wdrożenia. Kontrola hosta z 9 sierpnia 2026 r. potwierdziła, że nie są zainstalowane ani aktywne.

Aktualne jednostki znajdują się w `deploy/systemd/` i używają wariantów `dnd-pwa-web.service` oraz `dnd-download-web.service`.
